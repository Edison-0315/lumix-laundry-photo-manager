# 成片与独立运行组件验证

2026-11-04 晚，Apple Silicon / arm64。继续 P5，并提前完成内嵌 Python/Pillow 的本地构建接入；尚非全功能或发行完成。

## 功能

- JPEG 标记为成片会复制成片并把原片归入已修；RAW 必须关联导出的图像。
- 多版本关联、独立封面切换、单版本解除关联；解除的文件转入库内“取消关联保留”，不永久删除。
- 选目录按已存 SHA-256 查找缺失文件，复制回原受管位置，保留外部来源和数据库中的受管路径。
- 撤销最近归档受操作类型/来源库/日志格式及后续状态检查限制，不执行 Windows 历史日志。
- Finder 显示当前封面或原片；版本页也可定位单个成片。
- Photoshop.app 选择和 JPEG/RAW 打开入口使用 NSWorkspace，成功发出打开后记录 opened_at，不自动标记已修。写入期间阻止切库。

成片验证与摘要使用同一个禁止跟随链接的文件描述符；复制发布时继续校验摘要。来源为符号链接、图像无效或复制期间变化时拒绝关联。
