# 洗衣机管理器 0.10 验证记录

## 改动与范围

依据用户提供的 P1 滑杆、P2 侧栏和 P3 参考，以及“浅色玻璃侧栏和控件，照片工作区保留深色”的明确选择实现。apple-design 主导交互和连续动效，apple-ui-design 梳理层级，appleui-design-pro 指导局部光学材质。沿用 JavaScript/CSS/pywebview，不增加产品运行依赖，不修改文件管理后端。

侧栏改为浅色透色玻璃，装饰背景使用当前照片或当前范围首张预览，底部渐为乳白；主照片区保持中性深色，照片像素不参与滤镜。导航背景连续滑动，人物折叠可打断，长列表在单一导航区滚动，库管理和回收站固定底部。缩略图大小仍用原生 range，保留80–720和键盘操作，增加进度、数值与按压反馈；弹窗、悬浮操作栏、阶段选中块和预览工具栏统一浅色材质。

## 限制

玻璃为 Windows WebView2 的局部光学近似，非苹果原生渲染；静态地图最长边512纹理像素、缓存最多20项，未引入逐帧截图。减少透明度、高对比和强制色彩提供实色回退，减少动态取消空间过渡。

测试仅操作work下自建标记照片和库，没有操作用户真实SD卡或照片库。既有RAW、人脸识别和Photoshop兼容边界沿用前版，未新增用户实际PS保存流程的验证。
