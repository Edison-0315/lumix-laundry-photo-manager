# 回收站与恢复验证

2026-11-04 晚，Apple Silicon / arm64。P6 照片/人物/活动回收与恢复、显式永久删除已接入，整库系统废纸篓仍待实现。本轮仅验证新增及受影响范围，不重复既有来源、导入和成片套件。

## 已接入

- 所选照片移入应用回收站；原片、伴随文件、成片及已解除关联保留版本随照片整理，来源保留。
- 恢复保留照片 ID、人物、已修状态、封面和版本关系。原位置出现外来同名文件时分配新后缀，不覆盖。
- 删除普通人物分类时，活动中的照片与回收站中的归属转入待分类；固定合照和待分类拒绝删除。
- 活动照片全部移入回收站后才隐藏活动；部分失败保持活动可见；恢复照片会重新显示活动。
- 永久删除须在本机库回收站中显式确认。只依据本库的已提交移入记录，核对设备/inode 和摘要；外来同内容替换文件保留。
- 删除计划先持久化文件身份及私有隔离路径，再移动隔离和删除。崩溃或部分失败后保留 pending，可重试永久删除；恢复和普通写操作保持禁用。
- 已知空目录通过目录描述符执行 rmdir，不递归删除文件，不跟随链接，保护库根、元数据根和 staging。
- 回收站缩略图/预览只开放与 trashed_photos、照片 ID、资产 ID 匹配的受管路径，继续拒绝任意元数据目录或跨资产读取。正在永久删除的照片不开放预览。
