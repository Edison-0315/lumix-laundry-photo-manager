# 片集 0.4

Windows 11 本机照片分类与修图管理。完整解压“片集-Windows-0.4”文件夹，双击“片集.exe”。不需要安装 Python；需要系统的 Microsoft Edge WebView2 Runtime。启动失败时查看 `%LOCALAPPDATA%\Pianji\startup-error.log`。现有0.1–0.3照片库可直接打开；切换程序前关闭旧窗口。

1. 点左下“管理照片库”，可以“新建照片库”，填写名称并选择保存位置；也能打开已有照片库、切换最近照片库。移除最近记录只移除入口，保留全部文件。不同照片库使用互不包含的独立目录。
2. 在“SD 卡选片”先选读取 JPEG 和 RAW、仅 JPEG 或仅 RAW，再点“选择来源”。默认逐层浏览子文件夹，双击文件夹或侧栏目录进入，单击选择/取消并支持多选。照片同样单击多选、Shift连续选择、拖动框选；双击只看大图、不改变此前选择。滚轮缩放大图、拖动平移，缩略图支持80–720及Ctrl加滚轮。读取中可取消，保留之前的选片结果。单个文件或目录不可读时跳过并列出路径及错误码，其他可读照片可继续选片；完全无法读取则保留上次结果。程序不修复 SD 卡文件系统。
3. 点“导入所选”，未设置照片库时自动打开照片库管理，可新建或打开已有库；取消保留 SD 选片。活动名称可从已有建议选择、输入新名称，或点“新建活动”先创建；主界面活动标题旁“＋”也能新建活动。再选择JPEG和RAW、仅JPEG或仅RAW。上方“格式”可筛选带 JPEG 或 RAW 的照片，导入格式默认跟随筛选。跨来源目录选择的照片一起导入；只复制源文件，同组JPEG、RAW、XMP关联保留。
4. 在照片库选择活动，点“识别人脸”。识别在本机运行，同活动内分组；明确多人进入合照，无脸或不确定进入待分类。漫展遮挡、妆容与路人会影响结果，请检查并手动纠正。
5. 照片库“全部人物”默认显示人物文件夹，双击人物后显示选出原片、已修原片和成片子文件夹，再双击进入照片；“平铺照片”可一次浏览当前范围。单击文件夹或侧栏活动/人物可选择/取消并多选，双击打开。人物标题箭头可收起列表，右键人物区可添加人物；右键普通人物可重命名或删除分类。删除分类把照片移回同活动“待分类”，保留照片、修图阶段与成片。照片选中后点“调整人物”可移动归属。右键已选项保留多选，右键未选项只选择该项；底部“更多操作”、Shift+F10、菜单方向键与 Esc 均可使用。
6. 在设置里选择或填写自己的Photoshop.exe位置。选JPEG或RAW打开，修好后手动“标为已修”。仅打开不会自动标记；JPEG、RAW及XMP一起归档。不要在文件移动时让其他软件重写同一文件。
7. 已修好且作为JPEG导入的照片，可直接“标为成片”；RAW需先导出。Photoshop另存导出后，在右侧“选择导出图片并关联”。程序复制成片、保留导出来源，并将原片归入已修；允许多个导出版本和更换封面。
8. 成片页可以“取消成片”，右侧可“解除此版本关联”。取消后从成片列表移除，原片和修图阶段保留；复制的成片移入照片库`.片集/取消关联保留`，不删除图片。成片页仅显示成片相关操作；切换人物、活动、阶段会清除旧的库内选择，避免误改其他范围的照片。
9. “打开成片文件夹”后，可自行通过微信分享。恢复待修会保留已有成片；最近一次人物/阶段归档可撤销，后续状态已变化时会要求手动调整。
10. 在照片库右键“删除照片…”或按 Delete，确认后整组 JPEG、RAW、XMP、成片及取消关联保留版本移入该库的`.片集/回收站`。左侧“回收站”可单张或全部恢复，恢复保留人物、修图阶段与成片关联，同名文件会加后缀避免覆盖。回收站仍占用磁盘空间；本版没有永久删除和清空功能。SD 选片区不提供删除来源照片。

JPEG 与 RAW 分目录时，可直接选择任意一种格式的文件夹单独读取。若希望自动关联，请选择共同父目录，将两种格式分别放在同一拍摄目录下的 `JPEG`（或 `JPG`）与 `RAW`（或 `RW2`）子目录；每种格式只有一个同名文件时配成一张，可从两个文件夹分别查看。在共同父目录扫描后，先导 JPEG、再导 RAW 会补充到同一条照片。无歧义配对才自动关联，不会把不同拍摄目录里的重号照片强行合并。配对照片优先使用 JPEG 预览，RAW 单独读取时使用 RAW 自身预览。

照片按“活动 / 人物 / 选出原片或已修原片 / JPEG或RAW”存储，成片在“活动 / 人物 / 成片”。先导入JPEG后再补导RAW，会依据原始内容关联到同一张照片，保留人物、修图阶段及成片。`.片集`目录内的SQLite数据库记录关联与恢复日志，**备份应包含整个照片库和隐藏目录**。同一照片库每次只能在一个程序窗口内打开。设置、日志、缓存位于`%LOCALAPPDATA%\Pianji`，正常使用不联网、不上传照片。

文件被占用、SD卡拔出、磁盘满时会保留已完成的照片，并尝试回滚当前组；关闭占用程序后，在设置里重试文件恢复。源文件和已有不同内容的目标文件不会被覆盖。请根据错误结果核对并重试。自行移动库内文件后，右侧“定位缺失文件”可选择包含原文件的文件夹，按内容校验复制回原位置。

当前验证范围和限制见`docs/0.4-验证记录.md`。已对本机日志所指 RAW 目录做只读扫描：137 张 RAW 可读，并完成其中一张真实 RAW 预览与源文件 SHA-256 未变化验证；不代表已修复 SD 卡损坏或覆盖所有 RAW。Photoshop 安装与保存流程仍未在用户安装上联调。

源码开发：Python 3.12 x64，在独立虚拟环境安装`requirements-dev.txt`，运行`python run.py`。`python packaging/fetch_models.py`按固定提交下载并校验模型（仅开发/重新打包需要）。用`python -m pytest`运行测试；便携包由`packaging/build.ps1`构建。锁定依赖见`requirements-lock.txt`。
