# 洗衣机管理器 0.7

Windows 11 本机照片分类与修图管理。完整解压“洗衣机管理器-Windows-0.7”文件夹，双击“洗衣机管理器.exe”。不需要安装 Python；需要系统的 Microsoft Edge WebView2 Runtime。应用和程序图标采用 LUMIX 字标。启动失败时查看 `%LOCALAPPDATA%\Pianji\startup-error.log`。现有0.1–0.6照片库可直接打开；切换程序前关闭旧窗口。为兼容已有库，设置目录 Pianji 和库内 `.片集` 元数据目录保留原名。

1. 点左下“管理照片库”，可以“新建照片库”，填写名称并选择保存位置；也能打开已有照片库、切换最近照片库。移除最近记录只移除入口，保留全部文件。不同照片库使用互不包含的独立目录。
2. 在“选片”先选读取 JPEG 和 RAW、仅 JPEG 或仅 RAW，再点“选择来源”。主区文件夹单击选择/取消、可多选，双击进入；侧栏目录单击直接进入。照片同样单击多选、Shift连续选择、拖动框选；双击只看大图、不改变此前选择。滚轮缩放大图、拖动平移，缩略图支持80–720及Ctrl加滚轮。读取中可取消，保留之前的选片结果。单个文件或目录不可读时跳过并列出路径及错误码，其他可读照片可继续选片；完全无法读取则保留上次结果。程序不修复 SD 卡文件系统。
3. 点“导入所选”，未设置照片库时自动打开照片库管理，可新建或打开已有库；取消保留 SD 选片。在“活动名称”下拉菜单选择已有活动，或点“新建活动”，创建后自动回到导入窗口并选中它。主界面活动标题旁“＋”也能新建；没有活动时须先创建才能导入。再选择JPEG和RAW、仅JPEG或仅RAW。上方“格式”可筛选带 JPEG 或 RAW 的照片，导入格式默认跟随筛选。跨来源目录选择的照片一起导入；只复制源文件，同组JPEG、RAW、XMP关联保留。
4. 在照片库选择活动，点“识别人脸”。识别在本机运行，同活动内分组；明确多人进入合照，无脸或不确定进入待分类。漫展遮挡、妆容与路人会影响结果，请检查并手动纠正。
5. 只有“全部人物”默认显示人物文件夹，文件夹内显示最多三张照片示例，空文件夹保留图标；双击人物文件夹直接进入该人物照片。侧栏活动、人物、来源目录全部单击直接进入，无多选；右键只管理当前条目。人物标题箭头可收起列表，右键可添加、重命名、删除分类。删除分类将照片移回同活动待分类，保留修图阶段、成片和缺失文件关联；文件被占用时会保留分类并报告错误。具体人物直接展示照片，用阶段标签筛选；全部人物可切换平铺。左上“返回”或 Alt+← 回到上一浏览位置，与“撤销归档”独立。主区照片和文件夹仍单击多选、双击进入或预览；底部“更多操作”和 Shift+F10 可打开右键菜单。
6. 点右上角齿轮进入设置，选择或填写自己的Photoshop.exe位置。选JPEG或RAW打开，修好后手动“标为已修”。仅打开不会自动标记；JPEG、RAW及XMP一起归档。不要在文件移动时让其他软件重写同一文件。
7. 已修好且作为JPEG导入的照片，可直接“标为成片”；RAW需先导出。Photoshop另存导出后，在右侧“选择导出图片并关联”。程序复制成片、保留导出来源，并将原片归入已修；允许多个导出版本和更换封面。
8. 成片页可以“取消成片”，右侧可“解除此版本关联”。取消后从成片列表移除，原片和修图阶段保留；复制的成片移入照片库`.片集/取消关联保留`，不删除图片。成片页仅显示成片相关操作；切换人物、活动、阶段会清除旧的库内选择，避免误改其他范围的照片。
9. “打开成片文件夹”后，可自行通过微信分享。恢复待修会保留已有成片；最近一次人物/阶段归档可撤销，后续状态已变化时会要求手动调整。
10. 在照片库右键“删除照片…”或按 Delete，确认后整组 JPEG、RAW、XMP、成片及保留版本移入该库的`.片集/回收站`。回收站支持单击多选、恢复所选、“永久删除所选”和“清空回收站”；永久删除须再次确认，**确认执行后不可恢复**，不影响 SD 来源或库中正常照片。永久删除核对移入时的文件身份与内容，外来替换文件不会自动删除。若过程中有文件占用或失败，显示“永久删除未完成”，该组暂不能恢复，关闭占用程序后重试永久删除；重新打开程序不会自动继续删除。回收站未永久删除前仍占空间。
11. 侧栏右键活动选择“删除活动…”，确认后该活动的正常照片及关联版本进入回收站，全部完成才移除列表项。取消或文件占用时保留活动和未完成照片；已完成的照片在回收站。恢复其中任意照片会恢复活动入口；原先单独删除的照片仍留在回收站。活动文件夹里的其他文件保留。已删除活动仍有回收站照片时不能同名创建；空活动或全部照片已永久删除时可以同名重新创建。
12. 单击照片，右侧显示组内实际文件大小（多文件列明合计和各类型）、拍摄日期、相机型号、镜头焦段、镜头型号、光圈、快门、ISO 和记录的曝光补偿；优先读取拍摄原片的 EXIF，未记录的参数不猜测。JPEG/RAW 格式显示在右侧上方缩略图右下角的半透明磨砂徽标中。左下回收站以红色区块和垃圾桶图标显示。
13. 删除人物、活动、照片组或永久清除回收站后，自动清理已知空父目录。旧版遗留可在“管理照片库”对应库中点“清理空文件夹”。含其他文件的目录保留，不穿过目录联接/符号链接，不删除未知内容。恢复照片时重建所需目录。空目录本身通常占用很少；文件在应用回收站内仍占空间，永久删除后才释放。
14. 管理照片库中的“删除照片库…”会显示完整路径、照片数和容量；输入库名确认后，将整个目录（含库内其他文件及应用回收站内容）移入 Windows 系统回收站。可从系统回收站还原，清空系统回收站后才释放空间。占用或不能回收时报错，不降级永久删除。删除当前库会关闭当前库并移除入口，来源选片保留；“移除记录”仍只移除入口。
15. 0.7 保留暗色选片工作台，采用圆润面板、统一 SVG 线性图标及半透明导航/详情/浮层。选中照片提供低强度背景色映射，照片本身不模糊；遵循减少动态与透明效果的系统设置。

JPEG 与 RAW 分目录时，可直接选择任意一种格式的文件夹单独读取。若希望自动关联，请选择共同父目录，将两种格式分别放在同一拍摄目录下的 `JPEG`（或 `JPG`）与 `RAW`（或 `RW2`）子目录；每种格式只有一个同名文件时配成一张，可从两个文件夹分别查看。在共同父目录扫描后，先导 JPEG、再导 RAW 会补充到同一条照片。无歧义配对才自动关联，不会把不同拍摄目录里的重号照片强行合并。配对照片优先使用 JPEG 预览，RAW 单独读取时使用 RAW 自身预览。

照片按“活动 / 人物 / 选出原片或已修原片 / JPEG或RAW”存储，成片在“活动 / 人物 / 成片”。先导入JPEG后再补导RAW，会依据原始内容关联到同一张照片，保留人物、修图阶段及成片。`.片集`目录内的SQLite数据库记录关联与恢复日志，**备份应包含整个照片库和隐藏目录**。同一照片库每次只能在一个程序窗口内打开。设置、日志、缓存位于`%LOCALAPPDATA%\Pianji`，正常使用不联网、不上传照片。

复制或归档时文件被占用、SD卡拔出、磁盘满，会保留已完成的照片并尝试回滚当前组；关闭占用程序后，可在设置里重试文件恢复。永久删除没有字节回滚，未完成组应在回收站重试。源文件和已有不同内容的目标文件不会被覆盖。自行移动库内文件后，右侧“定位缺失文件”可选择包含原文件的文件夹，按内容校验复制回原位置。

当前验证范围和限制见`docs/0.7-验证记录.md`。0.4 时已对日志所指 RAW 目录只读扫描：137 张 RAW 可读，并预览一张真实 RAW、校验源文件未变；本轮仅在自建测试数据上验证删除，不代表已修复 SD 卡或覆盖所有 RAW。Photoshop 安装与保存流程仍未在用户安装上联调。

源码开发：Python 3.12 x64，在独立虚拟环境安装`requirements-dev.txt`，运行`python run.py`。`python packaging/fetch_models.py`按固定提交下载并校验模型（仅开发/重新打包需要）。用`python -m pytest`运行测试；便携包由`packaging/build.ps1`构建。锁定依赖见`requirements-lock.txt`。
