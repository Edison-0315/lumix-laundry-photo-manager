# 本机预览版使用说明

仅 Apple Silicon（M 系列），当前版本 0.1.2 (3)。SwiftUI 原生界面，内置 Python 与模型；运行已构建应用无需安装 Python、Node 或 Xcode。构建目标 macOS 14 起；实际验证环境 macOS 27.2，其他系统版本尚未实机验收。系统液态玻璃在支持它的 macOS 上启用，旧系统使用原生材质回退。

## 运行

打开同目录的 `LUMIX 洗衣机管理器.app`。可先将 app 复制到自己的“应用程序”目录；照片库保持原路径。当前是本地 ad hoc 签名，未公证、不对外发布；不修改系统安全设置。本地生成的包和网络下载包的信任行为可能不同。

1. 在“选片”页或文件菜单选择照片来源，按文件夹、日期、格式筛选。单击叠加选择，Command/Shift 配合选择；空白处拖动框选，拖到边缘可滚动。空格切换选中，Return 预览。
2. 从文件菜单新建本机照片库，放在来源目录之外。导入选中照片或文件夹，选择活动；原始来源只读。新建失败会保留准备现场并报告路径，不自动删除其中的未知文件。
3. 在照片库整理人物、已修状态、运行自动人物整理；JPEG 可关联成片、选择版本与封面。Finder 可定位文件，Photoshop 需先在设置中选择实际安装的 app。
4. 照片、人物和活动可移入应用回收站，再恢复或明确永久删除。整库回收需输入库名，移入系统废纸篓。打开有未完成操作的库不会自动恢复，须先查看报告并显式处理。
5. 设置中可切换深色、浅色或跟随系统。帮助菜单可查看第三方许可。

## 当前边界

- 现阶段是 macOS 独立版；不向 Windows 库写入、不转换旧库。既有只读查看功能可保留。
- 本机库绑定创建路径和文件身份；暂不支持将整个库移动或复制到新路径后继续写入。新建库已支持同一路径 APFS 卷重新挂载。旧版无卷 UUID 的本机标记不自动修改。
- 一张 DC-S5M2 RW2 已只读验证；人物分类使用本机 YuNet/SFace。其他相机/复杂人脸样本、物理外置盘和 Photoshop 实际打开仍待补验，不保证所有 RAW 均可解码。
- 已验证主要键鼠工作流；完整 VoiceOver、系统辅助设置和更小屏幕专项暂缓，不切换系统设置。
- 文件恢复与删除会校验身份，无法确定归属时保留文件并报告；不要手工编辑库内数据库和日志。

## 从源码生成本机包

在仓库根目录运行 `/usr/bin/python3 -I -B macos/Packaging/package_local.py`。首次需网络准备固定摘要的运行时和模型，之后可使用本地资源。脚本用 Xcode 构建 arm64 Release，核验签名、资源、架构、许可摘要和动态依赖，生成 app、zip、使用说明和 package.json；不会推送、上传或公证。

验证细节见 docs 下各阶段记录与 IMPLEMENTATION_PLAN.md。按当前范围以核心功能可用为目标，本机包先交付使用；历史专项未验项不作为本轮门槛，也不宣称已通过。
