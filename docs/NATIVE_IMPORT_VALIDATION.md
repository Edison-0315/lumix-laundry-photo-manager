## 本次功能

来源页将单张照片与各浏览范围中所选文件夹的后代合并去重，使用冻结扫描结果导入。日期/格式或文件夹切换不会丢弃此前的照片选择。导入面板选择已有或新活动，以及全部已读取格式/JPEG/RAW；仅复制来源，展示新增、补齐、跳过、逐项错误与取消状态。新活动名称按 casefold 匹配已有活动；拒绝把新活动混入外来同名目录。

本机库支持创建人物、同活动人物归属、已修/待修、普通人物重命名与同活动合并。固定合照/待分类不能重命名或作为合并来源。重命名、归属与阶段通过文件事务同步路径和数据库；批量失败按照片组报告。最近记录保存最多十个入口，显式打开；旧库入口仍只读。关闭库释放后台锁，清空当前显示，不删除文件。

来源与照片库共用拖动框选组件：空白起拖、Command/Shift 叠加、Esc 恢复拖动前选择。边缘自动滚动和历史滚动位置恢复仍待实现。

未完成本机操作显示显式检查回滚入口。恢复只处理当前库自己的 macOS 日志，不执行日志里的 SQL；未知 partial 或外来文件保留。purge 仍不能通过此入口续作。结果报告显示保留现场的错误。
