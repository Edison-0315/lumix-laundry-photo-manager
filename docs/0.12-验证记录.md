# 洗衣机管理器 0.12 验证记录

## 请求与依据

用户要求窗口打开/关闭和文件夹进入/返回增加动画，延续四个skill及深色界面。阅读了[WWDC24 10145](https://developer.apple.com/cn/videos/play/wwdc2024/10145/)、[HIG Motion](https://developer.apple.com/design/human-interface-guidelines/motion)、[HIG Materials](https://developer.apple.com/design/human-interface-guidelines/materials)；采用稳定来源身份、短促成对的路径、可中断操作，以及功能层与照片内容的分层原则。Windows沿用pywebview/WebView2，不转换为SwiftUI。

## 改动

- 主窗口：Windows Form整体透明度打开220ms、关闭160ms，UI线程Timer按真实时钟推进；不调整窗口边界或重排图库。关闭仍执行既有任务停止、预览线程结束及库锁释放，closing/closed/finally共用一次清理。Windows动画关闭时立即响应。启动加载回调缺失时2秒可见性回退，避免窗口永久不可见；透明度异常降级正常生命周期。
- 应用弹窗：保留HTML dialog的模态、原生关闭和焦点语义，按触发位置轻缩放/淡入，关闭沿反向路径；退出表面不接收输入。快速重开从当前CSS显示值继续。
- 文件夹：人物和SD来源文件夹通过View Transitions一次性快照，将来源卡片与照片区匹配；返回按历史中的scope/key查找新生成的卡片，快照前恢复滚动。无API、键盘和减少动态直接更新；正常render取消过时ticket，防止旧导航覆盖最新选择。浮动操作栏独立为更上层的静态匹配快照，避免被照片区缩放画面遮住。

## 回归证据

- 新增窗口测试4项，先因模块缺失失败，实现后通过：开合存在中间值、启动中关闭延续当前值、重复关闭只完成一次、减少动态及加载前关闭不依赖计时器。
- `ui_v012.cjs` 最初未检测到人物/SD文件夹匹配过渡，弹窗也没有来源位置；实现后通过。补充最新侧栏意图、返回长网格滚动、快速进入/返回及清名检查。录制回看发现浮动操作栏被快照遮盖，新增失败回归后修复。最终8场景全部通过。
- 全部13组UI回归通过：ui_v012、ui_v011、ui_v010、ui_v09、ui_v08、ui_smoke、ui_boundaries、ui_feedback、ui_v03、ui_v04、ui_v05、ui_v06、ui_v07。光学数学检查另通过。Python全量107项通过，无跳过，包含新便携包模型、许可证与workspace-motion.js资源检查。
- 独立审查确认生命周期、最新意图、来源身份、滚动恢复与回退逻辑无阻断缺陷；浮动操作栏分层修复后另行复核，8场景重跑通过。

## Windows实际验证

- 源码原生Form开合检查：92次透明度采样，其中23个中间值，连续关闭cleanup一次。另阻断loaded处理，2秒回退后仍能显示与关闭，216次采样、24个中间值，cleanup一次。
- 实际0.12 exe隔离LOCALAPPDATA启动，通过Win32读取所属主窗口的Layered Window alpha：打开22个、关闭12个中间值；连续投递关闭后正常退出，退出码0。只针对该测试进程主窗口，未操作其他应用或真实照片库。
- 新包内UI在原生Edge WebView2 156验证：实际JPEG预览、横竖图、鼠标锚点缩放、空格选择、关闭保留结果、真实导入、1040×720、阶段滑块及弹窗。源文件SHA-256一致；条纹光学对照指定区410个像素显著变化。
- 文件夹实际录制包含进入、返回、快速反向及弹窗开合，采样确认匹配区域有多个中间尺寸。录制从原生WebView2合成器取得，仅抽取实际帧并保留时间间隔，不插值生成动画；不属于产品运行中的逐帧截图逻辑。最终日志与夹具路径见 `work/v012-native-package.log`。
- 实际exe的自测通过，退出码0：EXIF/文件大小、导入/人物/阶段/成片、人脸模型、回收站恢复、活动删除恢复、托管永久删除、整库Windows回收并只还原标记库、持久化和SD哈希不变。
- 交付前比较包内UI与源码字节，Windows/源码ZIP检查全部成员CRC并记录SHA-256。结果保存在 `洗衣机管理器-0.12-交付校验.json`。旧版交付物保留，本轮仅本地提交，不推送GitHub。

## 边界

仅使用work下自建标记照片/库和隔离设置，不操作用户真实SD或照片库。系统文件选择窗口遵循Win11自身行为。玻璃为WebView2局部光学近似；匹配快照要求浏览器支持View Transitions，缺少支持时功能正常直接切换。既有RAW、人脸和Photoshop兼容范围沿用前版。
