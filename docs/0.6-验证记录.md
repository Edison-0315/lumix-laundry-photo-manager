# 洗衣机管理器 0.6 验证记录

## 本次修改

导入活动由 datalist 文本建议改为明确的下拉菜单，创建后返回导入窗口并选中新增活动；没有活动时阻止空目标导入。侧栏活动右键可删除，正常照片组及关联版本先进入回收站，全部成功才隐藏活动；恢复照片时重新显示活动。保留旧库和 AppData 路径兼容性。

名称统一为洗衣机管理器，LUMIX 字标用于界面、窗口图标和 exe 图标；选片简化标题，设置仅齿轮图标，回收站增加垃圾桶和红色区块。右侧按选中项异步读取 EXIF 与实际文件大小，格式在上方缩略图右下角以磨砂徽标展示。JPEG 原片参数优先，RAW 元数据通过文件头读取，无需完整解码；参数未记录时不猜测。

## 范围

所有写入、删除和永久删除验证仅作用于自建临时数据。原生交互测试的 RAW 是文件操作夹具，真实 RAW 另行只读检查；本轮不宣称覆盖所有相机 RAW。没有在用户实际 Photoshop 安装上验证编辑、另存和退出流程。LUMIX 图标为按用户要求制作的字标图形。

交付包含“洗衣机管理器-Windows-0.6.zip”“洗衣机管理器-源码-0.6.zip”，外部交付校验 JSON 记录文件大小和 SHA-256；归档生成时校验全部 ZIP 成员 CRC。
