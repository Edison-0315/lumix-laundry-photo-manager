# 苹果风格交互精修 实现计划

> 使用 executing-plans 内联执行，test-driven-development 验证行为，最终由全新审查者检查。用户已指定主辅设计技能，并逐项确认预览行为；沿用 feature/photo-manager 工作区。

**目标：** 保留 0.7 工作流，改善大图预览的直接操作、浮层反馈和紧凑布局。

**架构：** Python/pywebview 桥接及文件操作不变。原生 JS 单独管理可打断的弹簧变换；CSS 管理轻量浮层状态，不引入产品依赖。

**技术栈：** Python 3.12、原生 ES 模块、CSS、Edge WebView2。

**规格：** 用户确认：滚轮围绕鼠标指向处缩放；左右键切图；每张始终先适应窗口；预览提供选中/取消按钮和空格键，退出后保留结果。现有 AGENTS.md 交互及文件安全规则继续适用。以 apple-design 为主，apple-ui-design 辅助。

## 全局约束

- 不改变 SD 只读、导入复制、照片关联、Photoshop 或删除后端。
- 保留单击选择/取消、多选、双击前选择、侧栏单击导航。
- 原片清晰，玻璃只用于导航和浮层；保留暗色和 LUMIX 品牌。
- 指针操作即时响应；动画可打断；遵循减少动态、减少透明度和高对比设置。
- 本地交付为 0.8，不更改或上传已发布的 0.7 正式版。

## 审查重点

- “只看已选”内取消当前照片不能使预览序列或选择状态损坏。
- 快速切图、Esc 关闭及迟到的预览结果不能显示旧图或重开窗口。
- 空格在按钮上不能同时触发原生点击而重复切换；键盘焦点关闭后回到有效原处。
- 不同宽高照片、最小/最大缩放、边缘拖动和取消指针均保持可恢复。
- 1040×720 窗口、长文件名、减少动态与快速关闭重开浮层仍可操作。
