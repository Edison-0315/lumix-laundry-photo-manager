# 0.10 通透侧栏与控件 实现计划

> 使用 writing-plans/executing-plans 内联执行；先写回归，再实现；最终独立审查。起点 9a0838e，沿用 feature/photo-manager。

**目标与规格：** 用户提供 P1 缩略图滑杆、P2 当前侧栏、P3 浅色玻璃参考，认为原液态玻璃不好看，要求大胆改进侧栏设计和动画。用户已确认“浅色玻璃侧栏和控件，照片工作区保留深色”。apple-design 主导连续交互，apple-ui-design 梳理层级，appleui-design-pro 提供局部折射材质。

**方案：** 保留全部工作流；侧栏变为浅色透色玻璃，以当前照片或当前范围首图作为局部背景，底部渐为稳定乳白；照片网格仍为中性深色。导航、活动、人物、来源以各自单一的滑动玻璃选中层反馈，移除金色竖线与实心灰块。缩略图控制改为轻薄玻璃胶囊、清晰进度轨道、玻璃圆滑块和数值；80–720范围与键盘语义不变。其他悬浮控件/弹窗使用一致浅色材质和深色文字。

## 约束

- 单击/双击/多选、右键、相册层级、预览快捷键和全部文件安全规则保持。
- 侧栏材质固定，长导航独立滚动，底部库管理与回收站可达；长路径默认显示库名，完整路径保留在提示。
- 背景取色仅限装饰层，不对照片像素应用颜色/滤镜；空库不伪造照片。减少透明度/高对比使用实色，减少动态取消空间转场。
- 选中层重定向来自当前显示值，键盘即时；滑杆不重写原生输入，不延迟更新缩略图。
- 本地 0.10 交付，不覆盖 0.7–0.9。
