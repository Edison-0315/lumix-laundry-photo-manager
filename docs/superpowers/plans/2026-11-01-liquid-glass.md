# 0.9 液态玻璃与连续动效 实现计划

> 使用 executing-plans 内联执行，test-driven-development 验证，最终独立审查。当前 feature/photo-manager，起点 84df48e。

**目标：** 按用户明确选择“明显增强”，在暗色工作台的悬浮操作栏、阶段切换和弹窗加强边缘折射与流动感，照片内容清晰。

**规格：** 本轮对话；apple-design 主导，apple-ui-design 辅助布局，appleui-design-pro 的 optical-core/web-glass 指导 SDF、背景采样位移、分层材质；保留 AGENTS.md 与 0.8 确认的操作。

**架构：** 原生 JS/CSS 与现有弹簧，不增加产品依赖。生成静态 SDF 位移图，SVG feImage/feDisplacementMap 仅作用在背景装饰层；前景按钮不失真。不每帧截图/重建位移图；局部图尺寸受限、缓存，几何变化再生成。使用实际 Edge 像素对比证实折射，不只检查 CSS 字符串。

## 边界

- 本地 0.9 交付，后端与已发布 0.7 不变。
- 选片/框选/键盘切图保持即时反馈；动效不等待数据，也不阻断重复操作。
- 适应窗口、鼠标锚点缩放、空格选片、主区与侧栏选择规则不变。
- 仅有限局部背景折射，照片表面不滤镜化；减少透明度/高对比/强制色彩时回退；减少动态时立即切换。
- 所有验证只用自建夹具；不写用户真实 SD、不改变照片库文件管理。

## 审查重点

SVG 支持语法不代表真正折射，必须像素验证；滤镜不得作用于前景文字或照片本体；动态装饰不可重复订阅、泄漏 filter 或缓存。
阶段条重复快速切换、照片展开时滚轮打断、加载中关闭/重开、只看已选退出仍正确。
悬浮操作栏不得遮住最后一行照片或拖动框选；系统偏好改变后即时回退，不出现透明不可读的控件。
