# 模块化整理规格

以已验证的 0.12（e3fa8e6）为基线，在 Desktop/LumixGpt 中继续开发。保留 Python + 原生 ES modules + pywebview/WebView2，不迁移 SwiftUI，不改变外观、交互、公开桥接接口、照片库格式或文件操作规则。

前端按应用外壳、选片任务、导航侧栏、照片详情、照片库/人物/回收站对话框、共享状态查询与界面工具分工。入口只组合模块；业务模块通过明确回调请求刷新，不反向导入入口。状态只有一个实例，纯查询可用独立状态测试，不读取 DOM。

后端 Library 保留兼容门面；导入、人物、成片、回收站/活动分别由独立业务模块实现。每个库仍只拥有一个 Catalog、FileJournal、RLock 和 LibraryLock，服务不能独立建立连接事务或线程池。Bridge 保持原生窗口、授权、会话和任务边界；扫描与预览读取可独立定位。

新工作区可独立运行和打包，构建产物默认留在本项目内。旧工作区和交付版本保留，不发布 GitHub。提供模块地图，说明以后改哪项功能应看哪些文件。沿用已有完整 Python/UI 回归与必要的新模块行为测试；验证打包后嵌套 ES modules 可加载。
