# 片集 0.4 验证记录

## 根因与修复

本机应用日志中多次扫描失败，回溯定位 discovery.py 的 Path.is_symlink/lstat：一条 RW2 和一条 JPG 属性读取抛出 WinError 1392，整次后台任务随之失败。上版的文件夹配对改动没有覆盖这个异常，根因不是格式是否同目录的配对逻辑。

根据 [Microsoft 系统错误码说明](https://learn.microsoft.com/en-us/windows/win32/debug/system-error-codes--1300-1699-)，1392 为 ERROR_FILE_CORRUPT。新版将文件属性、子目录检查、目录枚举和照片信息读取按条目隔离，保留出错路径、阶段与错误码；不静默忽略，也不写入/修复源卡。可读结果照常发布，全部不可读和取消时保留之前选片；读取前可指定只读 JPEG 或 RAW。

活动新增显式主界面和导入对话框入口，创建真实库内空目录，严格检查名称、同名活动和路径。人物侧栏可折叠，支持右键添加、重命名、删除。删除普通人物将全部托管原片和成片移回同活动待分类，回收站引用也更新；占用失败/取消保留有效分类，不删除图片，固定分类受保护。

全部人物采用人物文件夹→阶段子文件夹→照片的层级，提供平铺照片和面包屑。照片、文件夹、活动及人物列表统一单击切换多选、双击进入/预览且保留双击前选择。文件夹全选和 Ctrl+A 不操作被层级隐藏的照片。已将持续交互规范写入项目 AGENTS.md。
