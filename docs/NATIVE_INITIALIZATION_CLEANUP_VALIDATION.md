# 新库初始化与空目录清理

2026-11-05，Apple Silicon，使用自建临时目录；不操作用户库或 Windows 参考项目。

## 行为

新库先在目标同级的隐藏 `.lumix-create-UUID` 目录准备。目录、元数据和初始数据库通过目录描述符创建，初始化前复核原目录/数据库身份，库锁和标记写入绑定准备阶段持有的元数据目录。完成 schema、标记和同步并关闭准备会话后，使用 renameatx_np / RENAME_EXCL 发布最终目录，再打开最终位置。

已存在或竞争出现的目标不覆盖、不作为新库返回；初始化失败释放锁，保留准备现场并报告路径，不自动递归删除准备目录或其中未知文件。标记记录最终库路径，目录/数据库身份在同卷改名后保留；正常创建返回最终会话，随后使用原有生命周期锁。失败准备目录不是可自动恢复的库，不执行其中历史日志。

清理只处理已知路径下的空目录。先记录身份，通过迭代器只读取一个条目确认空，再通过同一排他改名原语移到 `.片集/staging/empty-UUID`，核验后 rmdir。原公开路径出现替换目录时保留替换项；若隔离后有新文件到达，删除失败便尝试排他还原。还原被外来目标挡住时保留两边，并报告隔离路径。永久删除、人物和活动操作的结果会传递清理问题，同时如实保留已完成的业务结果。

不宣称抵御同用户恶意进程持续替换私有隔离命名空间；此处沿用已有私有隔离/身份核验边界，不增加自定义文件系统或 SQLite VFS。
