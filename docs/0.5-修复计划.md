# 片集 0.5 计划

规格依据：本轮六项反馈。继续现有独立产品仓库 feature/photo-manager 内联执行，使用 systematic-debugging、writing-plans、test-driven-development 与 UI/UX Pro Max。

- [x] 永久删除：回收站单击多选，选择永久删除、一键清空；明确不可恢复确认。仅删除已托管的库内回收站资产（含保留版本），不碰 SD 或正常照片，不递归删除未知文件。独立持久删除记录在首个 unlink 前提交；部分失败禁止恢复并允许重试，重启不会自动执行不可逆动作，替换后的外来文件受身份及哈希保护。真实临时目录测试先 RED 后 GREEN。
- [x] 人物分类删除：复现缺失关联资产导致 _fresh_assets/digest 失败，归档时跳过缺失文件但更新定位路径、保留元数据；外部占用仍清楚报错并保留分类。侧栏改成单击导航、无多选，右键只针对当前条目，消除固定分类残留选择干扰。
- [x] 浏览：仅全部人物用人物文件夹；具体人物、固定合照/待分类直接展示照片，阶段按钮继续筛选。主网格仍单击多选、双击打开。文件夹最多三张缩略图、懒加载与两路队列复用，空目录保留图标。
- [x] 导航：显示返回按钮，记录当前库和来源扫描范围内的浏览历史，恢复活动/人物/日期/格式/布局/SD 目录和滚动位置；不恢复过期照片选择；切库/重新读源清理不适用历史，Alt+Left 提供键盘返回。撤销归档与浏览返回分开。
- [x] 浏览器回归先失败再实现；更新此前与侧栏多选/阶段文件夹冲突的测试。单次新上下文审查两项发现均修复复查通过，完整 78 项 Python、六组浏览器、原生 WebView2 和便携包验证通过后归档交付 0.5。

## 文件边界

permanent.py 管理不可逆删除记录及恢复约束；catalog/bridge/library 提供受库锁保护的入口和缺失资产删除人物修复。navigation.js 管理浏览历史；gallery.js 复用缩略图队列绘制文件夹预览；dialogs.js 管理回收站选择与确认。AGENTS.md 按最新用户要求更新侧栏例外。

## 裁决

Ruling: 用户要求的是添加永久删除功能，开发验证只删除自己创建的临时库数据；不会在本轮代为清空用户现有回收站。
Ruling: 侧栏为单击导航；单击多选规则保留在照片、主区文件夹及回收站列表。具体人物不再显示阶段子文件夹，点击即看全部该人物照片。
Ruling: 永久删除发生部分文件失败时无法回滚已删除字节，保留“永久删除未完成”记录并禁用恢复，提示关闭占用程序后重试；不能假装仍可完整恢复。
