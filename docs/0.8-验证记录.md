- PyInstaller 重新构建 Windows 0.8，输出资源含 viewer.js 和 motion.js。用打包后的实际 UI 资源再次在原生 WebView2 验证缩放/选片/混合横竖图和紧凑窗口；截图位于 work/v08-native-1793503510428796700。

## 实现边界

- 玻璃为现有 WebView2 半透明/模糊材质，非苹果原生 Liquid Glass；照片内容不模糊。
- 手势平移即时更新，松手使用可中断弹簧回弹；菜单和弹窗只做短暂 transform/opacity 转场。减少动态时直接定位；旧 WebView2 不支持离散转场时保留原生开关语义。
- 本轮没有改动扫描、配对、人脸、Photoshop、归档或删除逻辑。沿用既有 RAW/SD/Photoshop 兼容边界；不声称覆盖用户真实设备的所有照片。
- 仅本地交付 0.8；已发布的 v0.7 正式版、历史版本和宣传视频保持原样。
