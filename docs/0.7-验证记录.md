# 洗衣机管理器 0.7 验证记录

用户反馈涉及目录残留、无法删除照片库，以及界面图标/圆角/材质。

## 行为

- 成功移动或永久删除后，对已知托管文件的父目录执行非递归 rmdir，清理至库边界或元数据根；非空目录、库外路径和目录联接保留。历史残留可在“管理照片库”点“清理空文件夹”，候选取自活动和操作日志。
- “删除照片库…”显示路径、照片/文件数和容量，须输入库名称确认；验证目录身份与内容快照、库锁及来源范围后，关闭文件句柄并交 Windows IFileOperation 系统回收站。失败可重开当前库，不降级永久删除；“移除记录”仅删除最近入口。
- 圆润三栏工作台、统一 SVG 图标、导航/详情/弹窗的磨砂材质和选中照片的低强度背景映射；照片像素保持清晰。保留多选、双击预览与侧栏单击导航。

设计参考 [Apple Materials](https://developer.apple.com/design/human-interface-guidelines/materials)。系统回收语义参考 [Microsoft IFileOperation flags](https://learn.microsoft.com/en-us/windows/win32/api/shobjidl_core/nf-shobjidl_core-ifileoperation-setoperationflags)，使用强制回收标志并在不允许回收的预删除回调中抛出取消异常。

## 本轮证据

- 初始 10 项回归全部失败，复现人物目录、回收站目录残留和缺失的整库删除 API；实现后通过。另复现“回收站文件已缺失、资产子目录仍在”的失败并修复。
- 最终全量 **103 项通过**，含便携清单、模型校验和 15 项本轮回归，无跳过；**8 组** Edge 实际 UI 模块回归通过。旧冲突恢复测试现在显式创建外来文件父目录，以适应空目录已清理的新行为，冲突保护断言保留。
- 真实原生 WebView2：活动下拉导入、EXIF、人物删除后目录消失、历史空目录清理、活动删除/恢复、整库删除的名称校验与取消均通过。真正 Windows 回收站出现自建测试库，随后仅还原该库；照片、外来测试文件和 SD 来源哈希全部不变。
- 1440 与 1040 宽度截图检查无横向溢出；实拍参数右侧仍可见。设计检查器的按钮阴影问题已修正。空图库的大块留白及 11–12px 的路径/辅助控件提示属于本地桌面照片工作台的空状态与紧凑标签；静态检查器未连接 pywebview，另用真实原生与注入桥接的 UI 回归验证实际交互。

- 独立审查发现“原片缺失时，人物/活动的旧空目录仍残留”，新增 2 个真实缺失文件回归先失败再修复：提交前持久化全部已知旧父目录、成功后清理，并对已删除人物/活动范围收集历史日志候选。另注入异常验证目录清理不会回滚已提交的文件与元数据；审查者独立复跑 15 项回归并关闭问题。
- 已重建最终 exe，复制到中文及空格目录启动：真实 WebView2、参数、模型、导入/归档/成片、回收站恢复和永久删除、整库系统回收与仅还原自建库均通过，退出码 0。真实 0.6 exe 生成的独立旧库由新代码打开，照片哈希保持不变，空活动删除同步清理本地目录。最终原生界面流程亦复跑通过。
- 交付为 Windows 0.7 免安装 ZIP 和源码 ZIP；外部交付校验 JSON 保存文件大小、SHA-256，生成归档时验证全部成员 CRC。

自动空目录清理遇到占用等错误时会保留目录并写入日志，可在管理照片库中再次清理查看具体错误；不影响已经提交的照片整理。

所有删除和系统回收验证只针对 work 下有标记的自建夹具；未清空用户系统回收站，未删除用户真实照片。未在实际 Photoshop 安装上验证编辑保存，不能将测试结果推广为所有相机 RAW 或所有磁盘都已验证。
