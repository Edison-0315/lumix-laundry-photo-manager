# 0.6 实现计划

规格：2026-10-28 用户的七项反馈；延续 AGENTS.md 的来源只读、照片组关联、回收站和单击选择规则。

1. 导入活动：用明确的单值下拉菜单替代 WebView 中不可靠的 datalist；可选已有活动、在同一流程创建活动，并验证实际导入目标。无活动时引导创建，不能空目标导入。
2. 活动删除：侧栏右键提供删除并确认；照片组及保留成片先移入现有回收站，全部成功才隐藏活动。恢复其中一张照片自动恢复活动；取消、占用或部分失败保留活动。只隐藏元数据，不递归删除文件夹或外来文件。空的已删除活动可按同名重新创建。
3. 详情：按选中项异步读取 JPEG/RAW 的实际 EXIF 和文件大小，原片优先，缺失信息显示未记录；读操作使用现有照片库文件读锁，快速切换时不覆盖新选择。格式在右侧上方缩略图右下角以磨砂玻璃徽标展示。
4. 界面与品牌：名称统一为洗衣机管理器；LUMIX 字标用于界面、窗口及程序图标。选片标题简化；设置仅齿轮图标且保留无障碍名称；回收站红色区块与垃圾桶图标。保持既有配置目录和照片库元数据路径兼容。
5. 验证交付：先观察新增回归失败，再实现并跑 Python、全部浏览器交互回归及原生 WebView2 流程；一次独立最终审查后生成 0.6 免安装包、源码包及校验记录。

Review Focus：删除活动时部分失败/取消/既有回收站/缺失文件/保留版本；恢复后活动可见；不修改 SD 和外来文件；EXIF 有理数和坏文件容错；异步详情竞态；导入已选活动和新建后返回；旧库兼容及真正 exe 图标。
