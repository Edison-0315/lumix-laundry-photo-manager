# 洗衣机管理器 0.11 验证记录

## 需求与实现

用户否定0.10浅色外观，明确选择回到深色侧栏，指出“选片／照片库”没有动效、动画生硬。参考[Apple Landmarks官方示例](https://developer.apple.com/cn/documentation/swiftui/landmarks-building-an-app-with-liquid-glass)的内容背景延伸、功能分层与连续运动。沿用Windows/pywebview原有技术栈；这是本地光学近似，不是SwiftUI原生渲染。

恢复深色侧栏、浮层及控件，弱化白色填充与双层亮边。侧栏接收照片的低强度色彩，选中层不再嵌套额外玻璃；照片保持中性、不加滤镜。修复导航跳变：来源区/人物区的ResizeObserver只处理自身，阶段栏几何变化不再重置侧栏spring。主区变更有200ms轻淡入，无需等待，快速反向沿用当前显示值；键盘和减少动态即时响应。

## 根因与回归

- 初始真实Edge逐帧测试发现导航切换中间位置为0，快速反向也失败。原实现对任意侧栏区的尺寸变化调用全侧栏jump；照片库显隐人物区和阶段栏时，把正在进行的导航运动送到终点。各区域尺寸观察隔离后，运动过程出现连续中间值。
- `ui_v011.cjs` 验证四组场景：连续中间位置与无终点跳变、快速反向延续当前显示值、主区淡入不阻塞操作、键盘/减少动态即时响应。淡入断言也先失败再实现。
- 独立审查指出按压缩放可能造成约1px几何差异；补充选中层高度0.1px容差回归，先失败。改为累计offsetParent布局坐标和offsetWidth/Height，排除前景按压变换后通过。复核确认各host归属正确，1040×720下长人物与来源滚动/切换，选中层位置及尺寸均在0.1px容差内。
- `ui_v010.cjs` 浅色断言按用户新方向更新为深色材质，保留10项交互/可读性/滚动/折叠/异步/偏好检查。最终12组UI回归全部通过，光学数学检查另外通过。末次布局坐标修正后重跑新旧侧栏回归和包内原生检查通过。
- Python全量103项通过，无跳过；末次仅UI修正后的新便携包资源/许可证/模型校验再次通过。
