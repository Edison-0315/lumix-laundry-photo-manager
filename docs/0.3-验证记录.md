# 0.3 修复验证记录

对应 2026-10-28 四项反馈，保留既有界面风格与选片交互。

- 分目录 JPEG / RAW：分别读取任意一种格式的目录；共同父目录下 JPEG/JPG 与 RAW/RW2 的唯一同名文件可配对，两个目录都能浏览该组。不同拍摄目录或有歧义的同名文件保持独立。新增格式筛选；同一扫描先导 JPEG 再导 RAW 补充到同一照片，保留人工人物。未选 RAW 无法读取时不阻止仅 JPEG 导入。
- 右键：已选照片保持多选，未选照片右键只选择该张；包含查看、调整人物、修图阶段、标为/取消成片、删除。成片页按阶段显示适用命令；SD 区只有选片和导入。底部更多操作和 Shift+F10 可打开菜单，方向键、Esc 与外部点击关闭。
- 照片库：应用内命名新建并选择保存位置、打开已有库、切换最近库、移除记录。目录独占创建，来源与库、库与库不能嵌套。取消首次导入建库保留 SD 选择。建库等待期间阻止 Esc 与返回，字段错误保留表单；迟到结果不能关闭新对话框。
- 删除：只在照片库提供，整组 JPEG / RAW / XMP、成片与取消关联保留版本移到库内回收站。日志保护移动与数据库提交，失败回滚；支持单张/全部恢复，保留人物、阶段和封面关联，目标重名加后缀。缺失文件仍保留记录。人物在回收站期间改名或合并后恢复到当前人物目录。回收站仍占磁盘空间，不提供永久删除。

验证方式：新增行为先观察失败再实现。Python 真实临时目录操作与浏览器真实 UI 模块分别验证；浏览器的模拟桥接仅用于交互测试。新建库、右键成片、删除/恢复、最近库切换也在真实 WebView2 桌面窗口和真实 Python 后台完成，测试 SD 全部源文件 SHA-256 不变。

独立审查提出 3 项 P2：缺失保留版本恢复路径、离线当前库最近记录移除、建库取消的迟到结果干扰对话框。均补充失败回归后修复；新增表单验证失败保持打开的回归。

最终验证：63 项 Python 测试通过（包含便携包清单与模型校验）；4 组 Edge 无头浏览器测试通过，覆盖原有 200 张多选/缩放/框选、扫描取消、过滤范围及外部保存预览重验，并新增菜单/回收站/建库/分目录格式交互。独立审查者复查 3 项修复通过，未发现这些修复的遗留问题。

限制：未接触用户真实 SD 卡、S5M2 RW2 或 Photoshop 安装。RAW 文件操作测试夹具不构成真实相机解码验证；配对预览优先 JPEG，单独 RAW 由 LibRaw 解码。使用的公开肖像仅在开发临时目录中验证，不随便携程序分发。

已复制之前 0.2 原生测试照片库，用 0.3 打开；2 张照片及其 6 个活动文件仍可用，文件 SHA-256 不变，兼容创建回收站表。

0.3 便携程序已构建并复制到含中文和空格的新路径运行，进程退出码 0。真实 WebView2 窗口、分目录导入、人物/阶段归档、直接成片/取消、导出关联、预览、回收站整组恢复、重新打开持久化和 YuNet/SFace 模型执行均通过。测试肖像检测 1 张脸；全部 SD 测试源文件校验值不变。原生选择目录在自动测试中仅替换为已指定的开发临时目录，没有访问用户照片。
