# 洗衣机管理器 0.9 验证记录

## 改动

用户确认明显增强玻璃折射与流动感。以 apple-design 主导，apple-ui-design 辅助布局，appleui-design-pro 的光学模型指导局部 SDF/位移图/SVG 背景采样；沿用原生 JavaScript、CSS、pywebview，不添加产品运行依赖，不更改文件管理后端。

悬浮底栏有末行滚动避让；阶段玻璃滑块连续重定向；弹窗内容独立滚动；鼠标预览从图库或详情缩略图展开，并可被缩放/切图打断。键盘和减少动态路径直接响应，透明度/对比/强制色彩偏好有实色替代。

## 范围与限制

玻璃为 Windows WebView2 中的局部光学近似，不是苹果原生 API；不声称适用所有浏览器或等同 Apple Liquid Glass。地图最长边不超过 512 纹理像素，静态缓存最多 20 项；只在几何变化时生成，鼠标移动不重建；无逐帧截图。

所有照片和库操作验证只使用 work 下的自建标记夹具，不操作用户真实 SD 或照片库。既有人脸、RAW 与 Photoshop 的兼容边界沿用前版，未对用户实际 PS 保存流程新增保证。
