# 片集 0.5 验证记录

对应本轮六项反馈，按用户最新要求更新侧栏规则，覆盖原先“侧栏也多选”的约定。

## 本次行为

- 回收站支持单击多选、取消、全选、恢复所选、永久删除所选、清空回收站。确认框明确照片/关联文件数量和不可恢复；取消不调用删除。仅删除对应已托管回收站文件，保留 SD 来源、正常照片和回收站目录中的未知文件，不递归删除目录。
- 独立 purges 表在首个文件删除前记录计划；部分失败和中断后可重试，已删字节不回滚，该组禁止恢复，重启不自动删除。首次操作核对移入回收站的已提交移动日志、文件身份和哈希，重试也核对已记录身份/哈希。文件在初次操作前或失败后被替换时保留并报错。
- 侧栏活动、人物和 SD 目录均单击导航，无多选；右键只针对该条目。只有全部人物默认展示人物文件夹，具体人物直接展示照片，阶段标签筛选原片/成片。主区保留单击多选、双击进入/预览。
- 文件夹卡片显示最多三张示例缩略图，空目录显示图标；图片采用现有懒加载和两路队列，不一次解码整个相册。
- 返回按钮和 Alt+Left 记录浏览活动、人物、布局、阶段、日期、格式、来源目录及滚动位置；切库/新扫描不沿用旧范围历史，返回不复活过期库内照片选择。
- 人物删除失败已复现：缺失资产导致 digest 失败；现在归回待分类时保留缺失关联、更新其路径，移动已有文件。外部占用依旧报错并保留分类，不删除照片。去掉侧栏多选也消除了残留固定分类让删除菜单禁用的问题。

## 回归与审查

初始 test_v05 的六项测试全部失败，再实现后通过。覆盖：整组/导出及保留版本永久删除、正常照片和 SD 源文件不变、重导入、未知文件保留、占用失败/重启重试、失败后替换文件、缺失原片人物删除。新增 ui_v05 先失败再通过，覆盖侧栏导航、直接照片、返回、缩略图、人物删除范围、永久删除取消/选中/清空。

独立审查发现首次永久删除前的外来替换文件缺少保护、点击当前活动重置阶段时漏记历史；分别新增失败回归后修复。外来文件测试包含不同内容和相同内容不同文件身份两种情况，审查者复跑八项 Python 回归和真实 Edge 测试通过。

最终完整测试：78 项 Python 通过（含实际便携清单、模型哈希）；六组 Edge UI 模块测试通过。原有 200 张框选/双击/缩放、读卡取消、过滤、成片关联与预览刷新均继续覆盖，旧测试已按新侧栏规则调整。

真实 WebView2 窗口与后台完成：文件夹图片示例、单击切人物、返回、含缺失 RAW 的人物删除并归回待分类、回收站选中永久删除取消与确认、清空回收站。所有永久删除都仅针对自建临时库；SD 测试来源 SHA-256 未变，另一张正常照片在被显式移入回收站前保留。本轮没有清空或永久删除用户现有照片库。

已实际打开先前 0.4 生成的自建测试库：兼容创建 purges 表，原 1 张照片、4 个托管文件的 SHA-256 保持不变。
