# 本地清理、照片库删除与玻璃界面 实现计划

> 使用 executing-plans 内联执行；先测试再实现，最后一次独立审查。

目标：落实 2026-10-29 用户三项反馈，保留既有选片、多选、人物和成片关联规则。
规格：本次用户消息及 AGENTS.md。
技术栈：现有 Python 3.12 / pywebview / SQLite / 原生 JavaScript 与 CSS。

## 决定与接口

- 文件移动或永久删除成功后，仅对已托管路径的空父目录执行 rmdir，直到照片库边界或元数据根；不跟随符号链接或 junction，不递归删除未知内容。历史残留通过“清理空文件夹”处理，候选来自活动和操作日志。
- 管理照片库同时提供“移除记录”和“删除照片库”。删除须先预览具体路径、照片数和文件容量，再输入库名称确认；已知照片库及路径身份校验通过后，将整个目录交 Windows 回收站。原有 SD 来源、相邻库和库外文件不操作。系统不能回收或占用失败时报告错误，不降级永久删除。
- 复用当前库读写租约和 OS 库锁；操作中或其他窗口占用的库不可删除。当前库成功删除后清空当前库及最近入口，保留来源选片。
- 新界面保留暗色照片工作台与三栏结构，采用圆角、统一 SVG 线性图标和分层半透明材质；模糊用于导航、详情、浮层，照片本身保持清晰。文字、焦点和选中状态需可读，支持减少动态效果。
- 用户明确要求磨砂效果，优先于 design-taste 默认禁止玻璃的风格规则。参考 Apple 官方 Materials 指南；沿用现有字体与配色，不引入在线字体或素材。

## 审查重点

目录清理不能删除非空或未知内容、越出库边界或穿过 junction；已删除人物的回收站照片恢复仍有效。
照片库删除不能仅移除入口或偷偷永久删除，需当前库正确关闭、占用失败可重开、预览目标被替换拒绝。
所有删除测试只针对 work 下自建标记夹具；SD 只读，原片/RAW/JPEG/成片关系保留。
玻璃图层不得遮挡照片、多选框或弹层；新增图标不能改变按钮名称、文本和原有选择语义。
