# 0.2 用户反馈修复

以2026-10-28用户明确提出的八项问题及交互修改为验收范围，沿用已确认界面。

1. 扫描：枚举和逐张读取EXIF都检查取消；取消不发布部分扫描、不覆盖已有来源。回归覆盖信息读取阶段取消和桥接取消结果。
2. 框选：卡片位置在起拖时统一读取，指针事件合并到动画帧，只更新变化的选中状态；禁止每次移动全量DOM读写。
3. 缩略图：JPEG用解码器降采样；不同照片可并行；相同照片合并请求；缓存清理批量执行。用大图和并发行为验证，不以小夹具耗时代表真实SD速度。
4. 子目录：默认按来源文件夹逐层浏览，支持返回上级、左侧目录和显式“全部子文件夹”；跨目录选片保留。
5. 成片：库内JPEG可直接标为成片，仍保留原片；RAW需先导出。支持取消全部成片及解除单个版本关联，已复制文件转入库内隐藏保留目录，不删除文件，原片修图阶段不变。
6. 操作范围：成片页使用成片操作，原片阶段按钮隐藏；人物/活动/阶段切换清除库内旧选择，操作仅作用当前可见选择。
7. 首次导入：无可用照片库时自动打开原生目录选择器（可新建文件夹），取消则停在原选择状态，选好后继续导入确认。
8. 单击切换选中/取消，多张可连续点选；双击仅预览并恢复双击前选中状态；Shift连续选择保留。

先跑失败回归，再实现；全套Python/UI测试、实际桌面桥接、便携包重建后交付。只使用工作目录测试文件，不扫描用户SD卡。数据库增加保留记录为兼容迁移，现有库可直接打开。
