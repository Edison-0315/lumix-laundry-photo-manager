# 旧库只读浏览验证

2026-11-04，Apple M2 / arm64，当前 macOS 27.2、Xcode 27.2。

已实现十张原版表的只读快照，保留原始 ID、NULL、整数、实数、文本/JSON、BLOB；照片的已修和主成片状态独立。界面支持活动、人物、阶段、回收站记录筛选，复用原生预览与参数详情，显示原库路径及读取报告。Windows 盘符和 UNC 需要用户指定完整旧根，按完整路径组件映射到所选本机根；不修改数据库内路径。

SQLite 只打开本应用创建的临时副本。主 DB 和 WAL 从只读、全路径拒绝符号链接的描述符读取，复制前后复核身份、mtime 和字节。未 checkpoint 的 WAL 行可读取；源 SHM 不创建或改动。非空 rollback journal 拒绝读取，不以 immutable 忽略 WAL。临时连接 query_only、trusted_schema=OFF；旧 operation payload/SQL 只保留为文本，绝不执行恢复。

新增六项兼容测试：十表和状态保留、未 checkpoint WAL、越界/缺失/符号链接诊断、缺表拒绝、UNC/盘符边界、恢复日志拒绝。测试夹具来自独立临时目录；源文件列表和 SHA-256 前后相同。SwiftPM 核心 41 项通过。

Xcode 完整回归中的核心 41、原生 8、来源 UI 4，共 53 项通过；旧库 UI 的报告入口因父容器覆盖辅助功能 ID、link 控件类型不匹配而未找到，手动中止该用例后修复。只重跑受影响用例：`Test-LaundryPhotoManager-2026.11.04_13-02-07-+0800.xcresult` 为 1 通过、0 失败、0 跳过，实际走通打开库、Windows 根映射、映射后的 JPEG 100% 预览、成片筛选、成片预览及十表报告。此前完整结果包为 `Test-LaundryPhotoManager-2026.11.04_12-55-07-+0800.xcresult`（53 通过、1 中止），不称为单次全绿。Release 构建、严格签名验证通过，架构仅 arm64。NSOpenPanel 的既有主线程警告仍存在。

边界：仅验证合成旧库和本机系统，尚无真实 Windows 照片库往返验收。单个 DB/WAL 文件暂限 512 MB；稳定文件复核不是跨进程写锁，打开前须关闭其他使用该库的程序。历史嵌套 payload 未逐类型解释或迁移，未知内容仅诊断、保留。库页框选/文件夹导航、外置卷身份与 Unicode 规范等价目录隔离、整库转换、写入/导入及日志恢复仍待后续阶段。Windows 旧库始终只读。
