## 主要功能

- **选片工作台**：从 SD 卡或文件夹浏览照片，单击选择或取消、支持多选与拖动框选，双击查看大图；缩略图大小可调，大图可缩放和平移。来源目录保持层级，读取中可取消，不可读条目单独跳过并显示错误。
- **JPEG / RAW 关联**：支持同时读取、仅 JPEG 或仅 RAW。格式分放在子文件夹时可以分别浏览；满足无歧义配对条件的同名 JPEG、RAW、XMP 关联为同一张照片，分开管理也能看到关联。
- **活动与人物**：应用内新建活动、建立和切换照片库。本机人脸识别按人创建相册，多人进入合照，无脸或不确定的先进入待分类；人物分类支持手动调整。侧栏单击进入、右键管理，“全部人物”以带照片示例的文件夹展示。
- **Photoshop 接力**：支持选择或填写自己的 Photoshop.exe 位置，按 JPEG / RAW 打开。修图后手动标为已修，避免把“打开过”误当作“修完了”。
- **修图与成片管理**：区分选出原片、已修原片和成片。支持直接标记 JPEG 为成片、关联导出图片、多个导出版本、更换封面与解除关联。打开成片文件夹后可自行分享到微信。
- **照片信息**：显示实际文件大小、拍摄日期、相机型号、镜头焦段、镜头型号以及记录的光圈、快门、ISO、曝光补偿。格式在缩略图右下角以半透明徽标显示；缺失参数不猜测。
- **删除与恢复**：照片和活动删除先进入应用内回收站，支持恢复所选、永久删除所选和清空；删除照片库需输入库名确认，并移入 Windows 系统回收站。删除人物分类会把照片移回待分类。
- **v0.7 整理改进**：清理已知托管空目录，照片库管理提供历史空文件夹清理；保留非空或未知目录，不穿过目录联接和符号链接。界面统一圆角、SVG 图标及磨砂导航和详情面板。

## 下载与启动

1. 下载 `LUMIX-Photo-Manager-Windows-0.7.zip`，**完整解压**，运行文件夹中的“洗衣机管理器.exe”。
2. 运行环境为 Windows 11 x64，需要 Microsoft Edge WebView2 Runtime；便携包不需要 Python。
3. 首次使用先创建或打开照片库，再建立活动；到“选片”中选择来源、选中照片并导入。
4. 可直接打开 0.1–0.6 的照片库。切换程序前关闭旧窗口，同一照片库每次只在一个窗口中使用。

## 使用说明

正常使用不联网、不上传照片，SD 来源只读、导入只复制。照片库的关联信息、回收站与恢复日志位于隐藏的 `.片集` 目录，备份应包含整个照片库及其隐藏目录。应用回收站中的文件仍占磁盘空间，永久删除后不可恢复。

人脸分组会受遮挡、妆容和路人影响，请检查待分类与合照并手动纠正。读取错误不会修复 SD 卡文件系统。Photoshop 保存完成后仍需手动标记已修；不同本机 Photoshop 安装环境需自行设置路径。
